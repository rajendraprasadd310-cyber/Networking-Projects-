# 🌐 Three Router Static Routing | Cisco Packet Tracer

## 📖 Overview

This project demonstrates the implementation of **Static Routing** in a three-router enterprise network. Three LANs are interconnected through serial WAN links, enabling communication between all connected networks using manually configured static routes.

---

## 🎯 Objectives

- Design an enterprise network with three routers.
- Configure IPv4 addressing.
- Implement static routing.
- Verify end-to-end communication.
- Analyze routing tables.

---

## 🛠 Technologies Used

- Cisco Packet Tracer

## 🖥️ Network Topology

### Devices

- 3 Cisco ISR4331 Routers
- 3 Cisco 2960 Switches
- 3 PCs

### Networks

| Network | Purpose |
|----------|---------|
| 10.0.0.0/24 | LAN 1 |
| 20.0.0.0/24 | LAN 2 |
| 30.0.0.0/24 | LAN 3 |
| 192.168.1.0/24 | R1 ↔ R2 |
| 192.168.2.0/24 | R1 ↔ R3 |
| 192.168.3.0/24 | R2 ↔ R3 |
